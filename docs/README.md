# Документация учебного проекта

Версия выпуска: 1.0.0

## Назначение
Пример проекта для практической работы по CI/CD.

## Функции
- completion_percent(done, total): процент выполненных задач.
- remaining_tasks(done, total): число оставшихся задач.

## Тестирование
Тесты запускаются через GitHub Actions из main.yml.
